# 实施计划（已按你的决定收口：P0 全做 + P1 全做 + 两包补测试，P2 不做）

## 1. A* 规划器（src/my_nav2_planner）

- **防对角穿角**：对角移动前检查两个正交邻格是否为硬障碍（与 tunnel_guidance_search 同规则）。
- **异常契约 + goal 早退**：goal 格硬障碍且 ≠ start 格 → 直接抛 `nav2_core::GoalOccupied`（省全图搜索）；无路径 → 抛 `NoValidPathCouldBeFound`；起终点出图 → 抛 `StartOutsideMapBounds`/`GoalOutsideMapBounds`；start 占据保持宽容（WARN 后继续规划，避免隧道场景脆弱化）。
- **cancel_checker 支持**：每 1024 次扩展检查一次，取消时返回空路径。
- **metrics 节流**：新参数 `metrics_min_interval`（默认 1.0s，<=0 每次都评估）；间隔内跳过整图距离变换，日志行照发、`min_lethal_obstacle_distance_m=-1` 标记跳过。
- **可测试性重构**：把栅格搜索核心抽成公开方法 `searchCells(costmap, start/goal cells, cancel)`，createPlan 负责坐标转换/异常/位姿构建/replan 事件/metrics。replan 事件机制（FORCED）不动。

## 2. B-Spline 平滑器（src/my_nav2_smoother）

- **OSQP 状态码收紧**：只接受 `OSQP_SOLVED`/`OSQP_SOLVED_INACCURATE` 且 `solution->x` 非空；x 阶段失败立即返回 false（跳过 y 求解），顺带消除 x/y 跨迭代状态残留。
- **容差统一**：settings 开 polishing、eps_abs/eps_rel 收紧至 1e-6、max_iter 提到 8000；走廊/overshoot 违规检查容差改为参数 `corridor_violation_tolerance`（默认 1e-4）。消除 "constraints remain violated" 噪音告警。
- **种子占用段跳过 overshoot 约束**：段 box 退化（seed 占用/出图）时不追加该段约束，防 QP 不可行导致整次平滑回退。
- **失败语义**：QP 失败回退原始路径并返回 true + WARN（对齐 EsdfG2o，避免 BT 无谓触发 ClearEntireCostmap）；内部尺寸不一致等真 bug 仍返回 false。
- **metrics 节流**：同 A*，`metrics_min_interval` 默认 1.0s。
